# 张睿｜可编辑简历

一个无需后端的 A4 简历编辑器。简历内容直接呈现在 HTML 中，可在网页上修改文字、替换照片、增删或调整模块，并通过浏览器打印导出为 PDF。

## 使用

1. 点击简历中的文字直接修改。
2. 悬停模块，使用右上角按钮上移、下移或删除。
3. 点击照片打开裁剪器，可更换图片、拖动构图、缩放并重置裁剪位置。
4. 修改内容会自动保存在当前浏览器，也可点击“保存”。
5. 点击“导出 PDF”，在打印窗口中选择“另存为 PDF”；纸张选择 A4、缩放 100%、关闭浏览器页眉页脚。

这是纯 HTML、CSS 和 JavaScript 项目，直接打开 `index.html` 或部署到 GitHub Pages 即可。
